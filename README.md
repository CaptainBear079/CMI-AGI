## Building from Scratch
If you want to build the project from scratch, you first need to download the source.

You can download the source using git or over the GitHub page ([Code -> Local -> Download ZIP](https://github.com/CaptainBear079/CMI-AGI/archive/refs/heads/main.zip))

Then you can install the dependencies with this command:
### make dependencies
in the directory of the project.

Next you can build the executables.

### If you only need the client or server executable, read Building the ______

You can just run
### make
in your terminal/command line.

## Building the server
You can use:
### make cmi-server
to build the server executable, it will be stored in "./build/".

## Building the client
You can use:
### make cmi-client
to build the client executable, it will be stored in "./build/".
